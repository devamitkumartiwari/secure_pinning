# secure_pinning_apple

iOS and macOS native probe-engine implementation for
[`secure_pinning`](https://pub.dev/packages/secure_pinning), in one
shared package built on Security.framework. Not meant for direct use by
applications — depend on
[`secure_pinning`](https://pub.dev/packages/secure_pinning) instead; this
package is picked up automatically as its iOS/macOS platform
implementation.
